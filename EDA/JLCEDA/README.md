# 嘉立创 EDA 硬件设计文件

该目录保存智能花盆的嘉立创 EDA（专业版）工程，与 STM32 固件相对应。

## 打开工程

使用嘉立创 EDA 专业版打开：

`花盆1.0_2026-08-13-18-56-40/花盆1.0.epru`

该工程最后使用的编辑器版本为 `3.2.149.88089769`。

## 内容说明

- `花盆1.0.epru`：可编辑的嘉立创 EDA 工程文件
- `project2.json`：工程基础信息
- `IMAGE/45163379283e83a7.webp`：PCB 布局预览
- `IMAGE/d15f0d89f469a5c5.webp`：原理图预览

> 改动硬件连接后，请同步检查 `USER/main.c` 中对应的 STM32 引脚定义，再编译和烧录测试。
